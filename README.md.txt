# GPay Transaction Analytics Dashboard

## Project Overview
An interactive Power BI dashboard built to analyze synthetic digital payment transaction data. The dashboard provides insights into transaction performance, payment methods, categories, and daily transaction trends.

## Dashboard Preview
![GPay Transaction Analytics Dashboard](dashboard.png)

## Key Features
- KPI cards for total, successful, failed, and pending transactions.
- Transaction success rate and transaction value analysis.
- Interactive filters for city, month, payment method, and status.
- Transaction status distribution using a donut chart.
- Daily transaction trend using a line chart.
- Payment method comparison using a column chart.
- Transaction amount by category using a bar chart.

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- Data Visualization

## Key Metrics
- Total Transactions: 5,000
- Successful Transactions: 4,704
- Failed Transactions: 235
- Pending Transactions: 61
- Transaction Success Rate: 94.08%

## Dataset
This project uses synthetic transaction data for learning and demonstration purposes. It does not represent actual Google Pay customer transactions.
